# Kivalliq Arctic Charr lcWGS pipeline

Population genomics pipeline for the manuscript *Fine-scale structure of a
postglacial Atlantic-Arctic contact zone in anadromous Arctic Charr
(Salvelinus alpinus), western Hudson Bay* (submitted to *Heredity*). The study
covers 13 populations (405 individuals) in the Kivalliq region, Nunavut,
sequenced by low-coverage whole-genome sequencing (mean 2.13×).

This repository contains **only** the scripts behind the figures, tables and
analyses reported in the manuscript. Exploratory analyses that are not in the
article (environmental RDA, dispersal assignment, management units, etc.) are
not included.

## Citation

Rubin B, Lecomte L, Faulkner C, Olsen A, Wiens L, Babin C, Normandeau E,
Dallaire X, Harris L, Moore J-S (submitted). Fine-scale structure of a
postglacial Atlantic-Arctic contact zone in anadromous Arctic Charr
(*Salvelinus alpinus*), western Hudson Bay. *Heredity*.

Data: NCBI SRA BioProject [accession] · Dryad [DOI] · Archived code: Zenodo [DOI]

## Requirements

- SLURM cluster with ANGSD (v0.941), ngsParalog, ngsLD, NGSadmix, PCAngsd and
  samtools (≥ 1.16, for `samtools consensus`)
- R and Python dependencies: `conda env create -f environment.yml`

**Important:** `RSCRIPT` in `config/00_config.sh` must point at the R inside
the conda environment created in step 0, not at a system R module:

```bash
export RSCRIPT="$(conda info --base)/envs/kivalliq-charr/bin/Rscript"
```

The bash scripts call `$RSCRIPT` explicitly, so activating the environment in
your shell is not enough. A generic system R can silently break the Mantel/IBD
step through an `nlme`/`vegan` conflict.

## Setup

0. Create and activate the analysis environment:
   `conda env create -f environment.yml && conda activate kivalliq-charr`
1. Edit `config/00_config.sh` — fill in the **USER-SPECIFIC PATHS** section
   at the top (pipeline root, reference genome, existing BAM/metadata
   source, program binaries, R installation).
2. Run `01_scripts/bash/00_setup.sh` once to create the working directory
   tree and pull in your BAM list / population / region metadata.
3. Place bamlists for the three reference samples at
   `${INFO_DIR}/bamlists/{JAY,LLS,DV}.bamlist` — they are not part of the
   13 Kivalliq populations and are not generated by `00_setup.sh`:
   - **JAY** — Arctic-lineage reference (Kitikmeot; Dallaire et al. 2025)
   - **LLS** — Atlantic-lineage reference (Lake Lilla Stensjön, Sweden;
     Saha et al. 2024, *Conserv Genet* 25:513–531)
   - **DV** — Dolly Varden (*S. malma*, Babbage River, Yukon), outgroup (H4)
     for the D-statistics and root of the mitochondrial tree
4. Basemap shapefiles used by the map figures (Fig. 1, 3, 6) are **not
   included**. They are Statistics Canada administrative boundaries
   (`lpr_000b21a_e.shp`) and NRCan CanVec hydrography (`waterbody_2.shp`,
   `watercourse_1.shp`). Download them separately and pass the containing
   directory as the `shp_dir` argument.

5. For step 14, download the ETOPO 2022 bathymetry at 1 arc-minute
   (NOAA NCEI), crop it to the study area and save it as
   `02_info/bathy/kivalliq_etopo.tif` (or set `BATHY_TIF`).

All scripts are run from the pipeline root (`BASE_DIR`).

## Reference genome

`GENOME` should point at GCF_002910315.2 / ASM291031v2 (Christensen et al.
2018). **Note:** the article describing this assembly was retracted (the
sequenced individual was probably a Dolly Varden or a hybrid); the assembly
itself is unaffected, and all samples, including the outgroup, were mapped to
it. The mitogenome used in step 12 (NC_000861.1, *S. alpinus*, 16,659 bp) is
part of this assembly.

## Main settings

- Genotype likelihoods: ANGSD `-GL 2`, `-minMapQ 30 -minQ 20`, MAF ≥ 0.05,
  data in ≥ 50% of individuals, total depth ≤ 8 × number of individuals
- Sex-linked regions removed (Beemelmanns et al. 2025; `SEX_CHRS` in the config)
- Paralogs: ngsParalog, BH-adjusted p < 0.001 (Dallaire et al. 2023)
- LD pruning: ngsLD, 200 kb window, no pair within 50 kb with r² > 0.1
- K selection: per-replicate NGSadmix results (10 replicates per K) were
  uploaded to the **StructureSelector** web tool, which computes the
  Puechmaille (2016) estimators (MedMedK, MedMeaK, MaxMedK, MaxMeaK).
  Retained K: global = 8 (K = 7 in Fig. S1), Rankin Inlet = 2, Naujaat = 5.
  This step is not scripted.

### Two distance calculations

- `compute_hydro_distances.R` (marmap) gives the pairwise in-water distances used
  for isolation by distance (Fig. 6d). For the lake and headwater sites (HOR,
  PAM, NOP), a channel length measured in Google Earth is added to the marine
  path (HOR: 402 km to open water).
- `34_marine_distances.R` (terra + igraph, 8-neighbour graph on ETOPO 2022)
  gives each site's distance to the eastern entrance of Hudson Strait, used in
  the variance partitioning (Fig. S2, Table S1). Sites are snapped to the
  largest connected marine component; HOR gets a fixed 300 km freshwater leg
  from the mouth of Chesterfield Inlet.

### Figures (run with `$RSCRIPT` from the pipeline root, no `sbatch`)

All figure scripts read `fig_common.R` (colours, geographic population order,
site coordinates, Heredity sizes), which must be in the same folder.

| Script | Output | Arguments |
|---|---|---|
| `36_Fig1_map.R` | Fig. 1 — study area | `<base_dir> <shp_dir>` |
| `37_Fig2_global_structure.R` | Fig. 2 — global PCA + NGSadmix K = 8; Fig. S1 — K = 7 vs K = 8 | `<base_dir> [K_main] [K_supp]` |
| `38_Fig3_regional_structure.R` | Fig. 3 — maps, PCA and NGSadmix within Rankin Inlet (K = 2) and Naujaat (K = 5) | `<base_dir> <shp_dir>` |
| `39_Fig6_differentiation_diversity.R` | Fig. 6 — design, FST, π, isolation by distance | `<base_dir> <shp_dir>` |
| `42_plot_admix_global_K.R` | Global NGSadmix for any set of K | `<base_dir> <K> [<K> ...]` |

Example: `$RSCRIPT 01_scripts/R/38_Fig3_regional_structure.R "$BASE_DIR" "$SHP_DIR"`.
Outputs go to `99_figures/heredity/` (PDF, and PNG/TIFF at 600 dpi).

## Repository layout

```

config/00_config.sh        — paths, filtering parameters, populations
01_scripts/bash/           — SLURM submission scripts
01_scripts/R/              — R analysis and plotting scripts
01_scripts/utils/          — Python helpers (Beagle file manipulation)
```
